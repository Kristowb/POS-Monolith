Catatan Khusus Jaringan IPv4

Supabase menggunakan IPv6 untuk koneksi langsung. Untuk mencegah galat jaringan di Railway (IPv4-only), konfigurasi monorepo ini dipaksa menggunakan JVM flag preferIPv4Stack=true dan Session Pooler port 5432.

Struktur Use Case Teknis

Lihat bagaimana data diproses antara DTO (Data Transfer Object) backend Spring Boot dan frontend Vue 3.

Alur Request

Client Vue mengirim email/password ➔ Spring Security memvalidasi dengan Database ➔ Mengembalikan JWT Token jika valid ➔ Token disimpan di Client LocalStorage.

Endpoint LoginPOST /api/v1/auth/login
Endpoint RegistrasiPOST /api/v1/auth/register
DTO LoginRequest (Java) 
package com.app.dto;

import jakarta.validation.constraints.NotBlank;
import lombok.Data;

@Data
public class LoginRequest {
    @NotBlank(message = "Username/Email tidak boleh kosong")
    private String username;

    @NotBlank(message = "Password tidak boleh kosong")
    private String password;
}

Alur Request

Ketika pengguna logout, token JWT dimasukkan ke daftar hitam database invalidated_tokens ➔ Setiap request yang datang akan dicek ke daftar hitam ini ➔ Token yang di-blacklist tidak bisa digunakan lagi.

Endpoint LogoutPOST /api/v1/auth/logout
Model Tabel Supabaseinvalidated_tokens
Model InvalidatedToken (Java) 
@Entity
@Table(name = "invalidated_tokens")
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class InvalidatedToken {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true, length = 1024)
    private String token;

    @Column(nullable = false)
    private Instant expiryDate;
}

Alur Otomatisasi CI/CD

Langkah otomatisasi yang dijalankan oleh runner GitHub Actions setiap kali ada push.

1

Git Push Trigger

Developer melakukan push kode ke branch master di repositori GitHub.

2

CI Build & Test

GitHub Actions mem-build backend dengan Maven JDK 17 dan frontend dengan Node 18.

3

Frontend Deployment

Aksi peaceiris/actions-gh-pages mempublikasikan berkas statis frontend ke branch gh-pages.

4

Backend Deployment

Railway memindai push baru, membaca railway.json, mem-build, dan men-deploy backend Spring Boot.
